Self-hosted watch-together video app. Clojure server, ClojureScript browser,
ffmpeg -> MPEG-DASH, one slime-green waterpark theme. You run it on your box,
upload your library, open a room, toss friends a link, everyone watches in
sync. You drive playback; viewers pick auto (best sync) or a locked
resolution and catch themselves up when their internet wobbles.

* Desktop app
A Windows portable exe (run it, no install) and a Linux AppImage on the
[[https://github.com/soniccyclone/goob-toob/releases][releases page]]. The app bundles its own JRE, ffmpeg, and cloudflared —
first run asks where your videos live, then the admin console opens with a
*sharing* card: copy the public tunnel link and toss it to friends. No
password, no terminal. The admin console listens on loopback only; the public
tunnel has no admin surface at all (see
[[file:plans/2026-10-12-desktop-distribution-releases.org][the distribution plan]]).

** Windows: first party
1. Download =goob-toob-win-x64-portable.exe= (~250 MB; carries its own JRE,
   ffmpeg, and cloudflared — nothing else to install). Put it anywhere;
   nothing is written outside its folder except your videos and a small
   config in =%APPDATA%=.
2. Run it. SmartScreen says "Windows protected your PC" because the exe
   isn't code-signed: *More info → Run anyway*. No admin prompt, no
   installer.
3. First launch asks /where should goob-toob keep your videos?/ — pick or
   create your library folder. Uploads, the database, and the generated
   streams all live under that one folder.
4. The admin console opens; the *sharing* card shows the public link once
   the tunnel dials (seconds). *copy link* → that's the party entrance;
   friends open it in any browser and install nothing.
5. Upload by dragging files onto the drop zone. Wait for each status to hit
   *ready* (ffmpeg builds a multi-bitrate stream per file, one at a time —
   transcode before the party).
6. *make room* on a ready video: the room link (already your public link)
   lands on the clipboard. Toss it to friends.
7. Open the room link yourself to host: play/pause/seek drive everyone; the
   video's native play button starts playback. Tick /co-hosts can drive/ if
   friends should steer too.

Good to know: the public link is a Cloudflare /quick/ tunnel — ephemeral, so
every launch gets a new URL (re-copy from the sharing card after a restart).
Nothing is exposed on your network: the tunnel dials out and the admin
console is loopback-only, which is why there's no password. The log lives at
=%APPDATA%\goob-toob-desktop\server.log=; the storage folder can be changed
anytime with the *change* button (the server restarts against the new
folder). To remove it, delete the exe (and =%APPDATA%\goob-toob-desktop=
for the config and log).

** Linux
Download the AppImage, =chmod +x=, run it — same folder picker and sharing
card; steps 3–7 above apply.

Building from source: =make uberjar && make vendor=, then
=cd desktop && npm install && npx electron-builder --linux AppImage= (or
=--win portable= on Windows; CI does both via
=.github/workflows/release.yml=).

Releases are cut by CI: every merge to =main= that passes tests gets the
next tag and a GitHub Release. Patch bump by default; put =[minor]= or
=[major]= anywhere in a commit message since the last tag to bump that part
instead; =[skip release]= in the merge's last commit skips the release.
=desktop/package.json= holds no real version — =release.yml= sets it from
the tag at build time, so there is no bump commit to make.

* Quickstart (podman)
#+begin_src sh
make image          # one-time: fedora + jdk + node + ffmpeg(libx264) + clojure CLI
STORAGE=/path/to/video/drive make dev   # dev loop: CLJS watch + server on :8080
# or production-style (assets baked into the image):
STORAGE=/path/to/video/drive make run
#+end_src

Then open http://localhost:8080, hit =/admin#, log in (=goob-dev-password=
unless you set =ADMIN_PASSWORD=), upload videos, make a room, share the link.

=make dev= mounts the repo live; =make run= uses the image's compiled assets.

* Env vars
| var               | meaning                                        | default          |
|-------------------+------------------------------------------------+------------------|
| STORAGE_DIR       | required: where videos/uploads/db live         | -                |
| ADMIN_PASSWORD    | container mode's admin password; *unset = desktop mode* (two ports, loopback admin) | - |
| PORT              | HTTP port                                      | 8080             |
| GOOB_ADMIN_PORT   | desktop mode: loopback-only admin port         | 8081             |
| FFMPEG_PATH       | ffmpeg binary (ffprobe must sit next to it)    | ffmpeg (on PATH) |
| TRANSCODE_WORKERS | parallel ffmpeg jobs (keep it 1 while hosting) | 1                |
| KEEP_ORIGINAL     | keep uploaded source after transcode           | true             |
| DB_PATH           | sqlite file                                    | $STORAGE_DIR/... |

* Sharing your party
** Cloudflare quick tunnel (works today, friends need nothing)
No account, no open ports (it dials *out* to Cloudflare), no tailscale:
#+begin_src sh
# one-time: grab the static binary
curl -fsSL -o ~/.local/bin/cloudflared \
  https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x ~/.local/bin/cloudflared

make tunnel        # background; prints a random https://<words>.trycloudflare.com URL
make tunnel-stop   # tear it down
#+end_src
The URL is ephemeral (new one each run, logged to =tunnel.log=) and quick
tunnels are rate-limited — fine for a party, not permanent hosting. The admin
password (rate-limited, 5/min) and the unguessable room tokens are the defense.

** Tailscale Funnel (friends need nothing)
#+begin_src sh
tailscale serve --bg 8080      # once
tailscale funnel 443 --bg      # publishes https://<machine>.<tailnet>.ts.net
#+end_src
Enable Funnel once in the Tailscale admin console. Funnel only fronts ports
443/8443/10000. NOTE: as of 2026-10-12 Tailscale is failing to publish public
DNS records for funnel hostnames on some tailnets
(https://github.com/tailscale/tailscale/issues/21698) — the funnel looks up
locally but is unreachable from the internet. Use the cloudflared tunnel above
until that ships a fix.

** Tailscale Serve (friends on your tailnet)
=tailscale serve --bg 8080= and share =https://<machine>.<tailnet>.ts.net= —
only tailnet members can reach it.

** Raw port forwarding
Works, but ships video + chat unencrypted. Last resort.

* How sync works
- The server holds each room's authoritative clock: media position + play/pause
  on a monotonic timeline. Host actions (play/pause/seek) update it and are
  broadcast; a heartbeat goes out every 2 s.
- Viewers estimate the server clock NTP-style (min-RTT ping samples), then
  apply a drift policy (=src/cljc/goob_toob/sync_core.cljc=):
  | drift          | action                          |
  |----------------+---------------------------------|
  | < 0.3 s        | nothing                         |
  | 0.3-1.5 s      | playbackRate nudge +/-5 %       |
  | > 1.5 s        | hard seek (the catch-up)        |
  | buffering      | wait it out, then the above     |
- The room never pauses for one stalling viewer; when their buffer refills,
  the policy snaps them back. That's the catch-up feature.
